Pentagon Boxed

Letter Boxed, but five-sided — and solvable in one word.

How to play
  • Click letters to spell a single word using all 15 letters.
  • Consecutive letters cannot be on the same side of the pentagon.
  • Each letter is used exactly once. There is one valid English word.
  • Use Backspace to undo, Clear to start over.
